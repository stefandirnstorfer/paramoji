# Paramoji

## What is a paramoji

A paramoji is a graphcial icon, rendered from continuous parameters. Unlike emojis they are parametric, not enumerated.
The icons feature various facial expressions with overlays, animations and coloring. They can be used to visualise
computationally generated states with emotional conotations.

[Try out your own](https://paramoji.org/editor.html)

## How can I use paramojis on my website

The easiest way to link the image directly. You can set the parameters from 0 to 100.

```html
<img src="https://paramoji.org/paramoji.svg.php?v=70&a=50&d=45&c=0&o=40"/>
```

[Full API description](https://paramoji.org/developers.html)
