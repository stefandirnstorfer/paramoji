# Paramoji

## What is a paramoji

A paramoji is a parametric emoji. It renders facial expressions
from five continuous parameters. It can be used to  visualize
computationally generated emotions with accuracy and with
arbitrary nuances. 

[Try out your own](https://paramoji.org/editor.html)

## What are the available dimensions of the paramoji

The paramoji renders from the following meaningful parameters:

1. *Valence* is the axis from bad to good, misery to pleasure, disagreement to agrement.
2. *Arousal* is the axis from calm to aroused, inactive to active, sleepy to alarmed.
3. *Dominance* is the axis from weakness to strength, fear to anger, submission to dominance.
4. *Contempt* is the axis from neutral to smug, vain, disdainful and contempt.
5. *Control* is the axis from uncontrolled to controlled, expressed to suppressed.

## What emotions can be represented with the paramoji

The paramoji parameterizes facial expressions; not all of them relate to confirmed
emotions. The seven emotions defined by Paul Ekman can be represented with reasonable
completeness and with arbitrary mixtures.

## How can I use paramojis on my website

The easiest way to link the image directly. You can set the parameters from 0 to 100.

```html
<img src="https://paramoji.org/paramoji.svg.php?v=70&a=50&d=45&c=0&o=40"/>
```
